# 0014 A page holds exactly what is printed on it; split words stay split

Decided 2026-10-04 (my call under Arjun's instruction to fix the evaluation's issues on my own; revisit if he disagrees). Updates decision 0007. The copy-editor no longer continues a sentence across a page break or starts a page "with the whole word" (`irriga-` / `irrigation`): those two instructions, together with Docling's cross-page joins, caused most of the evaluation's page-break regressions (duplicated paragraphs, restarted sentences, `fo-` / `forums.`). Now each page's Markdown holds exactly the text printed on that page; a page that starts mid-sentence starts with that fragment (`tion schedule changed in May,`). The continuity note still carries what is open (heading path, list numbering, table column names), and a table that continues on a new page still gets its column names and `*(table continued from page N)*`, as 0007 approved. The stitched `name.md` therefore shows `irriga-` and `tion` either side of a page anchor. This is the "keep pages faithful, which removes the duplication, and accept the split word" option offered to Arjun on 2026-10-03, after which he said "fix all these issues".
