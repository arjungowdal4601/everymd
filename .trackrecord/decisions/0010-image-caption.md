# 0010 Caption for single images, in the front-matter (module 6)

Decided 2026-10-03. When the input is a single image, the copy-editor's page note is written as a caption: one plain sentence saying what the image is (a scanned document: what, from whom, date, key number; a chart: what it measures and the main finding; a diagram: the process or system; a photo: what and where; a screenshot: which app or screen). No extra AI call. It is saved exactly as written as `ai_caption` in `name.md`'s front-matter (null when the AI layer is off) and as `caption` in report.json. Not a separate caption file. Pictures inside documents keep their AI-generated description lines; captioning them for the index is a possible later step.
