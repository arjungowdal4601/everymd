# 0007 Reading memory: a continuity note carried from page to page

Decided 2026-10-03. After each page the copy-editor writes a short continuity note (where I am in the heading path, what the page break left open, what to watch for), passed verbatim to the next page and saved in report.json and the page file. It covers all page-break continuity, not only tables: cut sentences, split words, list numbering, heading levels, split code/formulas/quotes, captions and footnotes. A table that continues on a new page gets its column names repeated with *(table continued from page N)*, and the table stays in the note until it ends. The old prompt rule "drop a repeated header row" is removed. Fixes land on the current page; earlier pages are not rewritten.

Approved by Arjun in Claude Code (voice dictation, quoted as transcribed): "in page number two, those table column names should be present ... it should not uh, move out until the table run is gone" / "this is one of the feature in the table ... you should not consider it as the only feature. And other feature is also page continuity. If some information is missed, due to previous page, now it has to be added here" / "yes build module 3, then explain module 4".
