# 0015 No copy-editor for inputs without page images

Decided 2026-10-04 (my call under Arjun's instruction to fix the evaluation's issues on my own; revisit if he disagrees). EPUB, email, and Office or web files that could not be rendered have no page image, so the copy-editor had nothing to check against: Docling's text comes straight from the file and is already exact. In the evaluation the copy-editor retyped the whole e-book (37,000 characters) and rewrote a licence clause and shortened a sentence; its only gains on the email were paragraph reflow and underscore escapes, and the escapes are now off in Docling's export. These inputs now skip the copy-editor (report: `copy_editor_input: "skipped: no page images ..."`); the brief is still written. A model that cannot see images (`EVERYMD_MODEL_SEES_IMAGES=false`) still gets a dedicated structure-only prompt for page-able documents.
