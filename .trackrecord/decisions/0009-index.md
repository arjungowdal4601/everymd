# 0009 Index: which pages contain what (module 5)

Decided 2026-10-03. Documents with pages or slides get `name.index.md`: a Markdown table `Pages | Section | What's there` (`Slides` for decks), with neighbouring pages grouped into ranges and important tables and figures on their own rows. It is written in the same final call as the brief (decision 0008), from the page notes and the continuity notes' heading paths, and saved exactly as written. Web pages get no index (their brief has an outline); EPUB, email and single images get none. Markdown only for now; a JSON index can come later if RAG code needs page ranges as data.
